# Contributing

OpenShield Africa welcomes responsible improvements to accessible cybersecurity, security UX, accessibility, documentation and safe testing.

1. Create a branch from `develop`.
2. Keep assessments non-intrusive and require explicit target authorisation.
3. Add automated tests for changed behavior.
4. Run `npm test` and `npm run build`.
5. Submit a pull request documenting risks and manual verification steps.

Never submit real credentials, private vulnerability details, or unredacted reports. Do not add exploit modules or high-volume scanning.
