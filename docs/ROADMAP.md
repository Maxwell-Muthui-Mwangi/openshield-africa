# OpenShield Africa product roadmap

## Delivered in prototype 0.1
- React-based responsive assessment dashboard
- Restricted local Node.js endpoint
- Five introductory transport/header configuration checks
- Static sample report clearly labelled illustrative
- Initial tests and GitHub CI

## Milestone 1 — trustworthy identity
- Authenticated organisational accounts and role-based permission
- DNS TXT challenge or website well-known challenge proving control of a domain
- Per-organisation domain registry and scan consent audit trail

## Milestone 2 — defensible assessment
- Isolated worker with controlled egress and public-address DNS enforcement
- Request concurrency, per-user and per-target rate limits, job queue
- TLS certificate details, policy-value validation, cookies and accessibility
- Secure encrypted results with data retention and deletion support

## Milestone 3 — funder evidence
- Public demo using only reserved sample data
- Open-source release notes, reproducible tests, accessibility audit
- Authorised pilot onboarding and interviews
- Exportable redacted reports and measurable, consent-based pilot outcomes

## Release criteria
No public remote-scanning endpoint until independent security review passes. The presence of a responsive UI is not proof of production readiness.
